# Audio reference

Audio translation is not established yet. The RSP task type, microcode address,
DMEM/DRAM contract, sample format, and host output path must be measured from
the WDC ROM and runtime.

`aspMain.us.toml` is intentionally a hand-maintained placeholder. Do not copy
an AeroGauge or Lamborghini audio configuration; the same symbol name does not
prove the same microcode or task contract.
