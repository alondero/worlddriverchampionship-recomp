# Glossary

- **Guest memory** — the emulated N64 RDRAM address space.
- **Generated image** — C/C++ emitted by N64Recomp or RSPRecomp.
- **Hook** — a narrow generated-code seam that calls a port-owned function.
- **Port** — hand-written code specific to World Driver Championship.
- **ROM fact** — a measured property of the supplied ROM, with evidence.
- **Dependency patch** — a reviewable diff applied to a pinned public submodule.
- **Headless run** — a bounded diagnostic execution using a non-player renderer.
- **Seam** — an interface where behaviour can be changed without editing its
  callers; tests should normally cross the same seam.
