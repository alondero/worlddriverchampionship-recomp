# World Driver Championship: Recompiled

Read [CONTRIBUTING.md](CONTRIBUTING.md) and the [documentation map](docs/README.md)
before changing the project.

## Project facts

- The supported ROM region, size, hash, and CPU code extent are intentionally
  unconfirmed. Record them in `rom-analysis.toml` and `docs/reference/rom.md`
  only after checking the actual dump.
- The intended build runs N64Recomp and RSPRecomp, then compiles generated code
  with the hand-written port, N64ModernRuntime, RT64, and RecompFrontend.
- `build.ps1` and `build.sh` are the executable build contract. Keep them,
  `BUILDING.md`, and `patches/README.md` synchronized.
- Windows uses RT64 with Direct3D 12; Linux and Android use RT64 with Vulkan.
  macOS support is not assumed until the window, input, and renderer paths are
  verified for this port.

## Source boundaries

- `RecompiledFuncs/` and `src/aspMain.cpp` are generated. Never edit them.
- `worlddriverchampionship.syms.toml` and `worlddriverchampionship.us.toml`
  are generated by `scripts/gen_syms_toml.py`. Change the generator inputs,
  then regenerate and review the diff.
- `rom-analysis.toml`, `aspMain.us.toml`, and `force_stub.txt` are reviewed,
  hand-maintained inputs.
- `src/` owns the hand-written port and narrow game hooks.
- `patches/` owns reviewable diffs against pinned public dependencies.
- `tools/` owns repeatable ROM, trace, capture, and evidence tooling; local
  emulator binaries and captures stay ignored.

## Runtime rules

- Guest memory is emulated N64 RAM. Every bridge must state address, width,
  byte order, units, owner, timing/thread, bounds, and failure behavior.
- SDL calls belong on the SDL main thread. Translated functions and port hooks
  run on their documented game boundary. RT64 owns display-list interpretation.
- A screenshot is evidence, not a regression test. Prefer a focused host test,
  synthetic RDRAM fixture, ROM-backed assertion, or bounded end-to-end run.
- A general renderer/runtime fix needs a minimal reproducer and upstream
  comparison. Keep game policy in this repository.

## Verification

Run the smallest relevant check and report what was skipped:

```text
python -B scripts/check_docs.py
python -m unittest discover tests
git diff --check
```

Do not claim a build, game run, visual comparison, ROM analysis, or sibling
project playthrough unless it actually happened. Do not commit ROM data,
generated output, local captures, or machine-specific paths.
